# Instagram Carousel Generator

Generate 5 Instagram-ready videos (1:1, 4:5, 9:16) from product description

## Use Case
E-commerce, product launches, social media

## Getting Started

```bash
cp .env.example .env
# Add your VAROSITY_API_KEY to .env

npm install
npm run generate -- --help
```
